# Fallback clip generation, 2026-09-26

The PRD's risk section asks for a pre-recorded fallback line in case ElevenLabs is slow or down during the live demo. The clips are generated by `pi/make_fallbacks.py` and are **not committed** (`assets/*.mp3` is gitignored). Run this once on every machine that will run the game, **including the demo Raspberry Pi**, with the ElevenLabs key in `.env`:

```bash
python pi/make_fallbacks.py --dry-run   # check the list, no key needed
python pi/make_fallbacks.py             # generate the missing clips into assets/
```

Then listen to each one once:

```bash
for f in assets/fallback_*.mp3; do echo "$f"; mpv --really-quiet "$f"; done
```
